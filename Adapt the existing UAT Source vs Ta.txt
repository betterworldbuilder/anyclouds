"Cutover Mobile Traffic Bench"

Add traffic ramp validation:
When the ramp is running, repeatedly load the center cutover phone through the cutover hostname and count where traffic lands.

Ramp stages:
- Demo Ramp: 50/50 -> 30/70 -> 0/100
- Safe Production Ramp: 5 -> 10 -> 25 -> 50 -> 75 -> 100
- Critical Banking Ramp: 1 -> 5 -> 10 -> 25 -> 50 -> 100

For each stage, run N requests against the cutover hostname.

- FLEX hit count
- other/error count

- p95 latency

- business transaction success rate

Add terminal command generation for each mobile action.

Health:
curl -k -sS -o /dev/null -w "http=%{http_code} time=%{time_total} ip=%{remote_ip}\\n" "$URL/health"

Load mobile:
curl -k -sS -o /tmp/mobile.html -w "http=%{http_code} time=%{time_total}\\n" "$URL/#"

Cutover hostname with Host header:
curl -k -sS \
  -H "Host: $CUTOVER_HOSTNAME" \
  -D /tmp/cutover_headers.txt \
  -o /tmp/cutover_body.html \
  -w "http=%{http_code} time=%{time_total} ip=%{remote_ip}\\n" \
  "$LB_URL/#"

Extract backend:
grep -i "X-Cutover-Backend" /tmp/cutover_headers.txt
grep -i "X-Backend-IP" /tmp/cutover_headers.txt

Ramp proof loop:
for i in $(seq 1 "$REQUESTS"); do
  curl -k -sS \
    -H "Host: $CUTOVER_HOSTNAME" \
    -D "/tmp/headers_$i.txt" \
    -o /dev/null \
    -w "$i,http=%{http_code},time=%{time_total}\\n" \
    "$LB_URL/health"

  grep -i "X-Cutover-Backend" "/tmp/headers_$i.txt" || true
done

Business login test:
curl -k -sS -X POST "$CUTOVER_API/login" \
  -H "Content-Type: application/json" \
  -d "{\"username\":\"$CUTOVER_TEST_USER\",\"password\":\"$CUTOVER_TEST_PASS\"}"

Account summary:
curl -k -sS "$CUTOVER_API/accounts/summary" \
  -H "Authorization: Bearer $TOKEN"

Safe transfer:
curl -k -sS -X POST "$CUTOVER_API/transfers" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "from_account":"TEST-CHECKING",
    "to_account":"TEST-SAVINGS",
    "amount":1,
    "reference":"cutover-mobile-test"
  }'

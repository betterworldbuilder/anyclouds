🗄 Single DB — Migration Steps
# Phase Action Result
0 Pre-flight SSH + MySQL reachability, disk space check Both endpoints confirmed live
1 Discover SHOW DATABASES on OSPC source DB list ready for loop
2 Dump mysqldump --single-transaction --master-data=2 per DB → gzip Compressed dumps in /tmp
3 Transfer scp dumps from OSPC → FLEX Dumps arrive on FLEX /tmp
4 Restore zcat *.sql.gz | mysql — CREATE DATABASE + import per DB FLEX DB populated
5 Validate Row count comparison OSPC vs FLEX per table Counts match — data integrity confirmed
6 Cut over Update app DB_HOST → FLEX IP, restart services App writes to FLEX DB
7 Cleanup Remove temp dumps from OSPC + FLEX /tmp Migration complete
🔄 HA DB + Replica — Migration Stages OSPC → seeds → Flex Primary → Flex creates own internal replica (OSPC disconnected after seed)
# Stage OSPC Role FLEX Role Action Result
1 Expose source HA VIP = seed source (port 3306) No DB role yet Verify Flex primary can reach OSPC HA VIP:3306 — TCP + root auth check on all 3 nodes Flex primary can connect to OSPC seed source
2 Verify engines Source version + GTID checked Flex Pri + Flex Rep both verified Check MySQL/MariaDB version + GTID mode on OSPC, Flex primary, Flex replica — must match major version All 3 nodes version-compatible
3 Seed Flex primary Provides dump — role ends here Flex primary receives full clone mysqldump --single-transaction --master-data=2 from OSPC HA VIP → restore on Flex primary → row-count validate OSPC disconnected — Flex primary is now self-contained clone
4 Bootstrap internal HA Not involved Flex primary seeds Flex replica Create REPLICATION SLAVE user on Flex primary for Flex replica; dump Flex primary → restore on Flex replica Flex replica seeded and ready to follow Flex primary
5 Start Flex replication Not involved Flex replica follows Flex primary CHANGE MASTER TO MASTER_HOST=FLEX_PRI_IP; START SLAVE on Flex replica — monitor Seconds_Behind_Master → 0 Flex has its own internal HA pair (no OSPC dependency)
6 Cut over Set read_only=ON → decommission Flex primary = new app DB endpoint Set OSPC read_only=ON; repoint app DB_HOST → Flex primary; Flex replica provides HA; 48h stability before OSPC retirement Flex HA pair fully independent — OSPC decommissioned

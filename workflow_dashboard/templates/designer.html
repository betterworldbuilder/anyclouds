Visual OpenStack FLEX Topology Builder and Deployer

Clone from OSPC topology on FLEX, link resources, and either generate a shell script or deploy directly with OpenRC credentials.

Prerequisites & Workflow:
  1. OpenStack CLI & Octavia CLI must be installed in the operator environment.
  2. FLEX OpenRC file (password version) downloaded — update it with your FLEX API password and place it in the ospcflex/ folder.
  3. Paste the deployment script XXXX_tenant_deploy.sh generated in Stage 1 into the Paste deployment script box.
  4. Click Import from Script — the topology will be extracted from the OSPC cloud definition.
  5. Then click: Validate Topology → Preview Plan → Generate Shell Script or Deploy Now.
    The script deploys the extracted OSPC topology on FLEX, automatically mapping to equivalent or superior FLEX flavors.
  6. Monitor progress in the Activity Log window in real time.

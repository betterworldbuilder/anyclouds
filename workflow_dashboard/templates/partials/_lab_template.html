How to add a new lab — five steps
#Do thisDetail
1cp _lab_template.html _lab_<name>.htmlIn workflow_dashboard/templates/partials/
2Replace ocnew with your prefixExactly 4 occurrences: -outer-wrap, -inline-toggle, -inline-body, -inline-arrow. Must be unique across the whole page.
3Set the three accent variablesOn the wrapper <div> — recolours headings, mission numbers, tables, notes and level bands in one edit
4Add the {% raw %}{% include %}{% endraw %}In _panel_training.html, above the closing </div> of .trn-wrap
5Add an index cardIn .trn-grid, with onclick="trainOpenLab('<prefix>')"
Why no stylesheet to copy Every .lab-* class is defined once in _panel_training.html. Earlier bands (ocqs-, ocqx-, ocqc-, ockl-) each carry their own copy of the CSS, which is exactly the duplication this template removes. Do not add a <style> block to a new lab.
One rule that is not optional Element ids must be unique across the entire rendered page — every panel is in the DOM at once, not just the visible one. A duplicated id silently breaks getElementById for whichever copy comes second. Prefix every id you add, not just the four in this file.

Notes — five kinds, pick by meaning not by colour
nm — the metaphor / framingOpens a mission. Uses the lab accent colour.
nc — complete whenGreen. Closes a mission with its exit criteria.
nw — cautionAmber. Version-dependent details, things that commonly go wrong.
nx — stop / destructiveRed. Gates, data-loss warnings, "do not continue until".
nr — asideGrey. Context, rationale, "why this matters", challenges.

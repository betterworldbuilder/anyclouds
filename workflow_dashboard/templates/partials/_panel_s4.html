                                        FLEX words people use now
                                        What it really means
                                    

                                
                                
                                    

                                        Top business boundary

                                        Main resource ownership

                                        In practice, old "tenant" thinking maps to FLEX project thinking. FLEX UI/docs explicitly surface project and domain.
                                    

                                    

                                        Person who logs in
                                        User / cloud user
                                        User
                                        Same basic concept, but FLEX user access is more formally tied to project/domain permissions.
                                    

                                    

                                        Team of users

                                        FLEX / Keystone makes groups a clearer identity object for assigning access by team instead of one-by-one.
                                    

                                    

                                        What someone is allowed to do

                                        Permissions
                                        Same word exists, but FLEX docs emphasize explicit role/permission setup for users.

                                        Access model

🔬 Internal UAT Tasks Reference

      
🔬 Internal UAT Tasks

      
    
        
  • Verify VM boot – Ensure VMs start successfully in Flex.
          
    openstack server list --project <project_id> -c Name -c Status | grep ACTIVE
    
        
    • 
        
  • Validate network connectivity – Confirm instances communicate as expected.
          
    ping -c 4 <flex_floating_ip>
    nc -zv <flex_private_ip> 22
    
        
    • 
        
  • Confirm storage accessibility – Verify volumes and storage resources are accessible.
          
    openstack volume list --project <project_id> -c Name -c Status
    ssh user@<flex_ip> 'df -h | grep /dev/vd'
    
        
    • 
      

      
👤 Customer UAT Tasks

      
    
        
  • Access confirmed – Customer confirmed access to the new Flex environment.
    • 
        
  • Confirm application functionality – Applications operating correctly after migration.

🛠 Automated Checking Commands

      

        

          
Databases (Service & Replication)

          
# MySQL Replication Status
ssh admin@<db_ip> 'mysql -e "SHOW SLAVE STATUS\\G" | grep "Running:"'

# PostgreSQL Replication
ssh postgres@<db_ip> 'psql -xc "select * from pg_stat_replication;"'

        

        

          
App Tiers (DNS & Services)

          
# Check DNS Resolution
dig @<flex_dns> +short <app_url>

# Verify Web Service HTTP 200
curl -I -s https://<app_url> | head -n 1

# Systemd Service Status
ssh user@<app_ip> 'systemctl is-active <service_name>'

        

        

          
Containers (Pod/PVC Health)

          
# Verify Kubernetes Workload Health
kubectl get pods,pvc,ingress -n <namespace>

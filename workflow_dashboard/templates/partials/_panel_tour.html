Quick Start

Get your first VM migrated in under 30 minutes

  1. 🔎 Stage 1: Run OSPC Scanner → pick 1 test VM
  2. 🚀 Stage 2: Open Linux Snapshot Mig → migrate VM
  3. ✅ Stage 3 UAT: Add server target pair → run health check
  4. 📈 Stage 2b: Review TCO savings vs OSPC baseline
  5. ⏱ Stage 4: Cutover DNS → production go-live

Stage 1 — Discovery & Assessment

Scan, analyze, and plan the migration scope

  • Run OSPC Infrastructure Scanner to inventory VMs
  • Scan networks, volumes, security groups, LBs
  • Define Business Systems with Business System Templates
  • App Dependency & Service Comparison analysis
  • Performance baseline (CPU, RAM, IOPS, network)
🎥 VIDEO TUTORIAL
YT Stage 1: OSPC Scanner & Assessment Guide (12 min)
🚀

Stage 2 — Migrations

VM Snapshot, DB Replication, Infra Clone, K8s

  • Full Business System Migration — orchestrate all components
  • Linux/Windows VM Snapshot & Volume Migration
  • App & Database Replication (MySQL, Postgres, MongoDB)
  • Infra Clone: networks, subnets, security groups, LBs
  • APPs Containerization with architecture templates
🎥 VIDEO TUTORIALS
YT VM Snapshot Migration — Linux & Windows (15 min) YT Database Replication to FLEX (10 min)
📈

Stage 2b/2c — Cost & Performance

TCO comparison and performance baseline on FLEX

  • Compare OSPC vs FLEX monthly cost per VM
  • TCO savings projection over 1, 3, 5 years
  • Post-migration performance benchmarking
  • Flavor right-sizing recommendations
  • Identify over-provisioned vs under-provisioned resources
🎥 VIDEO TUTORIAL
YT TCO Analysis & Performance Gain on FLEX (9 min)
✅

Stage 3 — Validation & UAT

Business-System-Aware testing and validation

  • Server target comparison (OSPC vs FLEX side-by-side)
  • Business system component health checks
  • Database comparison queries (SELECT 1, row counts)
  • Application endpoint smoke tests (HTTP health)
  • Performance readiness gate before cutover
🎥 VIDEO TUTORIAL
YT UAT Validation — Business System Checks (11 min)
⏱

Stage 4 — Cutover & Traffic Transition

DNS switch, traffic redirect, go-live coordination

  • Cutover checklist with owner assignments
  • DNS record updates and TTL management
  • Traffic transition (blue/green, weighted routing)
  • Business system cutover sequencing
  • Rollback plan with one-click revert
🎥 VIDEO TUTORIAL
YT Production Cutover — Zero-Downtime Transition (14 min)
🌿

Stages 5–8 — Operations & Modernization

Stabilize → IaC → GitOps → AIOps

  • Stage 5: Stabilization, monitoring, knowledge transfer
  • Stage 6: IaC, Backup, Disaster Recovery, Restore testing
  • Stage 7: GitOps, OpenCenter Modernization, CI/CD
  • Stage 8: AIOps, predictive scaling, continuous operations

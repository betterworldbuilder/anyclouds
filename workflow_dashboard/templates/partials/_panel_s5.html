Cutover Live Monitor Cockpit

Guided step-by-step cutover — run after Cutover TEST passes. Why: executes and tracks the real cutover once every test above is green.

📋 How to run a cutover
1 Click Start Cutover

Starts the timer and activates the cockpit. Steps stay locked until you click this first.

2 Run steps — manual or auto

Manual: click each step button left-to-right. Auto Chain: toggle Auto Chain: ON (top-right) before Start — steps run automatically in sequence, each with a 3-second cancel window.

3 DB in scope? (Step 4)

If no DB migration, uncheck "DB in scope" in Step 4 to skip it without blocking the final decision.

4 Final decision unlocks

All steps pass → Cut over PASS turns green. Critical fail → Rollback turns red.

5 Evidence & sign-off

Add operator notes → Archive Evidence → Export Evidence Package for customer sign-off.

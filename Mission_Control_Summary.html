OSPC2FLEX Mission Control Summary

Category Details
Workflow Stages Stage 0: Customer Migration Tracker (Backlog management)
Stage 1: Discovery & Assessment (OSPC/FLEX scanning & topology import)
Stage 2: Migration Pipeline (Shift & Lift Images, REHOST Apps/DBs, Kubernetes)
Stage 3: Validation & UAT (Automated cross-cloud checks & HTTP health tests)
Stage 4: Cutover & Handover (Traffic split, DB promotion, final sync)
Stage 5: Post-Migration (Stability tracking, artifact bundle generation)
Current Features • Single-Tab Mission Control: No CLI required, full GUI wrapper
• Live Execution: Real-time logs streaming to browser
• Visual Topology Designer: Drag-and-drop infra cloning
• Offline Guest Repair: Pre-boot image patching for networks
• Parallel Execution: Migrate multiple DBs/Servers simultaneously
• Kubernetes Portability: Auto-replication via Genestack/OpenCenter
• No Database Required: Stateless backend (CSV + local browser storage)
Available Migration Methods 1. Direct Shift & Lift (Images):
  • Production Mode (Live SSH-pipe disk without snapshot)
  • External Offload (Glance snapshot via Jump Host)
  • Direct Export (Direct read of live disk on Jump Host)

2. REHOST (Apps & Servers):
  • OSPC Infra Duplication on FLEX (using Brian's osflex tool)
  • Full Clone (13-layer sync: Users, Packages, Code, Cron, etc.)
  • Quick Install (Package-only mirror)

3. Database Replication:
  • Standard VM (Dump & Restore)
  • DBaaS Streaming (Direct memory pipe without local disk)
  • DBaaS + Replica / HA (GTID streaming & auto-pairing)

4. Kubernetes Migration:
  • Genestack / Kubespray (Ansible-driven)
  • OpenCenter (GitOps / FluxCD)
  • OSPC K8 to Flex Magnum (8-stage SSH export & transform)
